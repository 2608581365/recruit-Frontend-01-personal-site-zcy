# 羽你同行

一个介绍羽毛球运动的简易网页作品。

这个网站主要面向刚开始了解羽毛球的人，介绍羽毛球的基本信息、运动优点、相关资源、新手建议和比赛规则。

## 页面内容

- 关于羽毛球：介绍羽毛球的起源、比赛形式和场地球具
- 为什么推荐羽毛球：介绍运动带来的好处
- 资源推荐：提供羽毛球相关的网站和学习资源
- 新手入门建议：介绍球拍、球鞋、握拍和热身
- 比赛规则：介绍计分规则、边线规则和球场礼仪

## 交互功能

- 点击按钮展开和收起新手入门建议
- 点击规则标题展开和收起对应的比赛规则
- 鼠标移动到按钮、卡片和资源链接上时，会出现悬停效果
- 点击导航栏可以平滑跳转到对应页面区域

## 使用技术

- HTML：编写网页内容和页面结构
- CSS：完成页面布局、颜色、渐变、光晕、悬停效果和手机端适配
- JavaScript：实现内容展开、收起和按钮文字变化
